    Configure Live Google Gemini AI

    StudySync protects your credentials by never storing or exposing API keys in frontend code. The local Python backend (server.py) reads your key from the environment securely.

    1. Get a Free Google Gemini API Key:
      Visit Google AI Studio and click "Create API Key".
    2. Option A — Using a .env file (Recommended):
      In your studysync folder, create a file named .env with: 
      GEMINI_API_KEY=your_actual_key_here
      (You can copy from .env.example already in your folder.)
    3. Option B — Setting Environment Variable in PowerShell:
      $env:GEMINI_API_KEY="your_actual_key_here"
    4. Start the Server:
      python server.py
    🔒 Security Guarantee: The frontend code communicates only with your local server endpoint (/api/generate-study-plan). Your secret API key is never exposed to the browser or DevTools.
